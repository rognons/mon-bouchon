# Type de bouchon parmi les critères principaux, profil et portions dans l'affinage

Statut : acceptée (2026-10-24). Remplace en partie les n° 0001 et 0004.

Pour garder peu de choix sur le premier écran, les critères principaux sont
cinq : palier de prix, lieu, jour et service, type de bouchon, option
végétarienne. Le profil de mangeur et les portions deviennent des critères
secondaires, avec les mêmes règles (le profil d'un bouchon est un minimum
pour l'apprécier, les portions demandées sont un minimum), mais ne sont
jamais relâchés.

Conséquence non évidente : le brief faisait du profil de mangeur la façon de
tenir compte des invités ; on ne peut plus le choisir sur le premier écran,
seulement en affinant les résultats.
